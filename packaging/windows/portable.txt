lockmypdf portable mode

While this file sits next to lockmypdf.exe, lockmypdf keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the lockmypdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move lockmypdf with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\lockmypdf and
%LOCALAPPDATA%\lockmypdf) instead. If lockmypdfData can't be written (for example on a read-only
drive), lockmypdf says so and uses the per-user folders instead.
